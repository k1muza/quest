# Asset and licence documentation

The environmental image and packed depth use the existing KayKit Medieval Hexagon geometry under CC0 (Kay Lousberg, 2024). The original licence and models are retained in `../environment/assets/`. The original background is unchanged byte-for-byte. The generated six lathed faceted enamel-and-brass pawns are original to this project, produced by `bake_tokens.py` with numpy and Pillow. The corresponding depth sprite is geometry-derived, not a hand-drawn foreground cutout. Wayfinding plaques, token shadows, water glints and celebrations are original Canvas2D presentation graphics. No paid assets, external network calls or fonts are required. The application code and supplemental original assets have no separately chosen open-source licence; repository owner may choose one. CC0 attribution and permission apply to the upstream KayKit assets, not automatically to all project code.
