# Asset and licence documentation

The environment is derived from KayKit Medieval Hexagon geometry (Kay Lousberg, CC0, 2024); the original models and licence remain in `../environment/assets/`. Original procedural geological surfaces, agricultural clipping and Canvas 2D floating medallions are generated by project source. The historical pawn sprites and their depth texture are preserved but no longer bundled or loaded. No paid assets, external fonts or network requests are required. The upstream CC0 licence applies to the KayKit assets, not automatically to other project code.
